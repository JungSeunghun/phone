# Text input clipboard dependencies

OS clipboard reads use arboard 3.6.1 with image support disabled. arboard is MIT OR Apache-2.0; its MIT license is included. Windows additionally uses clipboard-win 5.4.1 (BSL-1.0) and error-code 3.4.0 (included license).

Sources: https://github.com/1Password/arboard, https://github.com/DoumanAsh/clipboard-win, https://github.com/DoumanAsh/error-code.
