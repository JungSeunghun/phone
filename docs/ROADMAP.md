# Roadmap

## Public release preparation

- MIT license, English/Korean entry documentation and support/evidence matrix.
- Contribution guide, issue/PR forms, private-report instructions and third-party notices.
- First-connection guidance and privacy-preserving diagnostic summary export.
- Review current files and Git history before changing repository visibility.

## First public release — still pending

- Publish reviewed macOS/Windows installers; configure OS signing/notarization where available.
- Configure the official stable HTTPS update feed and verify download/install/restart against it.
- Enable GitHub private vulnerability reporting and record a maintainer response channel.
- Verify installation on a clean Mac and a native Windows computer.

## Product follow-up

- Guided connection flow that can highlight the next action and recover from common setup failures.
- iPhone hardware validation for USB/Wi-Fi broadcasting, keyboard input, capture and recording.
- Native Windows + Android/iPhone hardware validation.
- Document additional tested phone/OS combinations and accessibility keyboard behavior.

No hardware verification, public release or hosting task is implied to be complete by a checked build or this document. New feature requests should describe concrete user problems before expanding this list.
