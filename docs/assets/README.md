# README preview artwork

`phone-mirror-demo.svg` is an illustrative desktop preview shared by the English and Korean READMEs. Its colors, labels, and layout are based on the existing Phone Mirror desktop presentation. It illustrates a USB session, settings, capture/recording controls, and a fictional phone planner.

Every element is authored as SVG vectors and text. The file contains no embedded raster images, external resources, scripts, device captures, recordings, connection codes, personal data, or real phone identifiers. The planner, times, and device label are fictional. The visible synthetic-demo label and captions distinguish the artwork from screenshots or hardware verification evidence.

The SVG is the editable source. Update it when the UI changes, keep the synthetic label, and use the same asset in both language versions. Preview it at desktop and narrow README widths before committing. This project-authored artwork is covered by the repository's MIT license.

`license-mit.svg` and `ui-languages.svg` are project-authored static badges for the existing license and UI languages. They use local assets rather than an external badge service. The CI badge links directly to the GitHub Actions workflow and reflects its current status.
